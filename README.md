# 🚀 ByteForge — Interactive Micro-Learning UI/UX Case Study

> **YuvaIntern UI/UX Design Track — Final Capstone Project**  
> **Role:** Lead UI/UX Designer | **Tools:** Figma, Miro, Maze, Design Tokens

---

## 📌 Project Overview
**ByteForge** is a micro-learning platform tailored for software developers and interaction designers. It replaces multi-hour passive video lectures with under-15-minute concept cards, in-browser code sandboxes with real-time feedback, and visual skill mastery analytics.

---

## 🎨 Design System & Specifications
- **Spatial Grid:** 8pt base grid system for all padding, margins, and layout components.
- **Color Palette:**
  - `Surface Base`: `#0B0F19`
  - `Card / Panels`: `#1E293B`
  - `Brand Primary`: `#4F46E5` (Indigo)
  - `Accent / Interactive`: `#06B6D4` (Electric Cyan)
  - `Status Success`: `#10B981` (Emerald)
- **Typography:** Inter (Headings & UI Labels), Fira Code (Editor & Syntax Highlight).
- **Accessibility:** Tested against WCAG 2.1 AA (Contrast ratio > 4.5:1 across all interactive states).

---

## 🧪 Usability Testing & Key Iterations
1. **Collapsible Workspace:** Desktop split-screen was enhanced with collapsible panels to prevent cramping on 13-inch displays.
2. **Actionable Linting:** Replaced generic "Error" warnings with contextual test hints.
3. **Milestone Feedback:** Added dynamic XP modals after exercise completion to reinforce learning streaks.
